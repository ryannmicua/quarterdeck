# Answer questions

Open **Needs attention** on the served page and select **Answer questions**. Each question has an ID you can cite later.

1. Pick an option or type in **Your answer**. To start with the suggested answers, select **Use all suggestions**. Questions without suggestions keep their current answers.
2. Review the answers. Edit any field or use **Undo changes** immediately after picking options or applying suggestions.
3. Select **Send answers**. The button counts the answers ready to send. You can send a few now and return for the rest.

**Answered** means Quarterdeck saved the decision. **Sent** means Firstmate received the note. If you see **Not delivered**, your answer remains saved. Once the inbox is available, select Send again. Retry uses the same note ID. To correct a sent answer, edit it and send again. Firstmate receives the correction as a new note.

The page shows times in your local time zone. Downloaded or rendered HTML shows a snapshot. Open the served page to send an answer.
