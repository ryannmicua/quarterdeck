# Watch Firstmate

Select **Watch** in the header of the served pages. It is read-only and has two
parts.

**Waiting on Firstmate** lists the items where Firstmate has yet to reply, newest
request first.

- **Messaged** is a conversation with an unanswered delivered message after the
  latest standalone update, if any.
- **Asked** is a question set where you asked Firstmate on a question or on the
  whole set, and it has not replied.

A reply linked to a request answers that request alone. An item stays in the
table while another request qualifies. Select a row to open the conversation
or go to the question or whole-set discussion. Failed deliveries stay on the
[Desk](use-the-library.md#when-an-item-moves), where you can open the item
and retry them.

**Current work** shows the workers and second mates from the last saved
reading, with the time it was taken. Watch never runs a check and uses the
saved reading even after it expires. The server refreshes that reading in the
background. Select [**Workers**](read-workers.md) to get a new reading or see
the full roster details. Current work needs
[`firstmate_home`](read-answers.md#connect-the-inbox).

Words on the page are in the [glossary](../reference/glossary.md).
