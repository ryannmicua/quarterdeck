# Ask Firstmate from a card

Use an ask when you need something explained before you decide. An ask leaves
the question's state and any saved answer intact.

## Ask about the whole item

Select **Ask Firstmate** in the page bar beside **Send answers**. Type in
**Message about this item**, then select **Send ask**. The inbox note names
the item, for example `ASK Q7 <ask id>`. Read replies in **Messages**
under **Item conversation** above the questions. Opening that conversation
acknowledges only its replies. The toolbar ask is available on question
items, including when all their questions are closed.

## Ask about one question

1. Open the served question page and type or edit a draft by hand in
   **Your answer or question**. Selecting an option or using **Use all
   suggestions** fills an answer. **Ask Firstmate** is available for a
   new hand-edited draft when
   [`firstmate_home` is configured](read-answers.md#connect-the-inbox).
2. Select **Ask Firstmate** below that field. The draft moves to **Messages**
   as a pending ask. The inbox note starts with `ASK`, the question ID and
   the ask ID. Use **Send answers** in the page bar when you're ready to
   submit your decision.
3. Read the ask under **Messages**. Once saved, it shows who wrote it, its
   local time, and **Sent** or **Not delivered**.

Firstmate's reply appears under the ask in its own conversation. It can include text,
links, and images. Reload the served page to see new replies. Select
**Messages** on the question to open its conversation and acknowledge the
replies shown there. If it is already open, close and reopen it to
acknowledge any new replies. The **Replied** badge stays while any reply is
unread, including on closed questions and items under **Reviewed questions**.

You can send another ask while waiting for a reply. The card shows every ask
from oldest to newest, with its replies underneath in the order they arrived.

## Retry a missed delivery

If an ask stays **Pending** after an interruption or shows **Not delivered**,
select **Send ask again** once the
[inbox is available](read-answers.md#connect-the-inbox). The retry keeps the
original ask and note IDs. Reopen a closed question before sending or
retrying an ask. If the configured Firstmate home has changed, Quarterdeck
refuses the retry.
If an ask never reaches Quarterdeck, reloading the page clears the draft and
you’ll need to type it again.

A validation error or confirmed conflict puts an unsaved draft back in the
field. If the Firstmate home changed, copy the draft before reloading.
For a validation error, correct the draft and send it again. A numbered draft
stays out of **Send answers** while
you correct it, including through editor undo and redo. To answer instead,
choose an answer option, then edit that answer if needed. **Undo changes**
brings back the preceding ask as an ask draft. You can also reload the page
to start a fresh draft. Clear the field before retrying a different pending
draft.
