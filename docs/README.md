# Documentation

Guides are grouped by purpose, following Diataxis:

- [Tutorials](tutorials/first-render.md) lead through a first successful render.
- [How-to guides](how-to/) cover installation, updates, removal, multiple-home configuration, scheduled refresh, [serving the always-current page](how-to/serve-the-page.md), [viewing in Lavish](how-to/view-in-lavish.md), and [requesting a Lavish page](how-to/request-lavish-page.md).
- [Read and track report reviews](how-to/review-reports.md) explains report IDs, CLI reading, and local review marks.
- [Keep the desk relevant](how-to/keep-the-desk-relevant.md) covers discarding, stale or current relevance, and the related-to-this-session section; [Use the cloud artifact](how-to/use-the-cloud-artifact.md) covers `export` and `import`.
- [Keep the captain board current](how-to/keep-the-board-current.md) and [write and publish a decision brief](how-to/write-decision-briefs.md) are Firstmate's side of the captain board.
- [Reference](reference/cli-and-config.md) lists CLI options and the JSON config schema; the [captain board file](reference/captain-board.md) documents the schema and the recency ranking of the "waiting on you" list.
- [Explanation](explanation/privacy-and-architecture.md) describes data flow and privacy; [the attention model](explanation/attention-model.md) explains what appears for review; the [captain desk experience log](explanation/captain-desk-experience-log.md) records what was tried, what worked, and the decisions behind the board.
