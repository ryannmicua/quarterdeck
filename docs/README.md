# Documentation

Guides are grouped by purpose, following Diataxis:

- The [tutorial](tutorials/first-render.md) saves a link and a list and opens the page.
- [How-to guides](how-to/) cover installing, updating and removing Quarterdeck,
  [saving items](how-to/save-items.md), [serving the page](how-to/serve-the-page.md),
  [asking Firstmate from a card](how-to/ask-firstmate.md),
  [talking to Firstmate about any topic](how-to/talk-to-firstmate.md),
  [replying from the command line](how-to/reply-from-the-command-line.md)
  and [reading the Workers page](how-to/read-workers.md).
- The [CLI and configuration reference](reference/cli-and-config.md) lists every
  command and config key; the [item store](reference/item-store.md) documents the
  file that holds the items.
- [Privacy and architecture](explanation/privacy-and-architecture.md) explains
  what Quarterdeck reads and writes and why items are stored by value.
